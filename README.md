## Laboratoria

### LAB01 — Analiza NDVI na podstawie danych Sentinel-2

Analiza danych satelitarnych dla obszaru Opola.

W ramach ćwiczenia wykorzystano kanały spektralne B04
oraz B08 satelity Sentinel-2 L2A.

Wskaźnik NDVI obliczono według wzoru:

NDVI = (B08 - B04) / (B08 + B04)

[Zobacz LAB01](LAB01_NDVI_Opole/README.md)
